# EconMod — работа над версией для Economic Modelling

Здесь пишется статья. Черновик собран из материалов FRL с учётом отзывов рецензентов.

- `econmod.tex` — рабочий черновик. Компилируется на месте, `latexmk -pdf econmod.tex`.
- `refs.bib` — исправленная и дополненная библиография, 27 записей.
- `docs/EM_restructuring_plan.md` — план переработки под профиль журнала, посекционно.
- `docs/Response_to_Reviewers.md` — черновик ответа рецензентам, прикладывается при трансфере.
